# Context Economy 0.1.0 provenance

This package publishes generic Context Economy primitives. Private campaign workloads, results and audit logs are not included or verified here.

The public design covers compact health read models, context source budgets with output reserve, bounded tool-result excerpts, capability projections and repository-map selection. The reduction keeps generic dependency-free primitives that are independently understandable outside PAI.

Excluded from this package: raw prompts, private prompt-evidence records, host and account identities, credentials, private paths, service endpoints, deployment topology, task/claim authority internals, protected evaluation intelligence, private failure corpora, and production configuration.

Only the included synthetic fixtures and benchmark support reproducible public behavior claims.

The implementation is licensed Apache-2.0 under the repository's selected public software strategy.
