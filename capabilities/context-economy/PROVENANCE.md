# Context Economy 0.1.0 provenance

This package is a new public-safe reduction of a privately verified PAI Context Economy campaign completed on 2026-09-17.

The design basis included compact health read models, typed context capsules with output reserve, bounded tool-result envelopes, capability projections, cursor continuity, repository-map selection, deterministic benchmarks, independent QA, a localhost canary, and exact rollback verification. The public reduction keeps only generic dependency-free primitives that are independently understandable outside PAI.

Excluded from this package: raw prompts, private prompt-evidence records, host and account identities, credentials, private paths, service endpoints, deployment topology, task/claim authority internals, protected evaluation intelligence, private failure corpora, and production configuration.

The internal frozen shadow result was p95 visible context 17,700 to 3,825 tokens (78.39% reduction), acceptance regression 0 percentage points, and false-success increase 0. The figures are published only as workload-specific provenance and are not represented as a universal benchmark.

The implementation is licensed Apache-2.0 under the repository's selected public software strategy.
