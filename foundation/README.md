# PAI Open Foundation

The Open Foundation is the public, reusable layer of PAI.

Its job is not to expose the complete private system. Its job is to publish small, complete assets that are independently useful and whose public claims are supported by evidence.

## What belongs here

Public candidates may include:

- schemas and interoperability contracts;
- bounded workflow/W_Flow specifications;
- reusable Skill recipes;
- verification and release patterns;
- synthetic fixtures and demos;
- public-safe examples;
- provenance and evidence contracts;
- starter Packs;
- documentation needed to use an approved public capability.

## What does not belong here by default

- PAI Mind/Chief private implementation;
- proprietary continuity/routing/adaptation intelligence;
- authority, credential or trust-root material;
- private runtime topology and operational configuration;
- protected evaluation corpora;
- deep accumulated failure/repair intelligence;
- customer, company or tenant evidence/data;
- private/sovereign execution internals;
- unfinished internal code copied merely because it exists.

## Qualification rule

A candidate should be published only when it is:

`USEFUL + BOUNDED + TESTED + VERSIONABLE + PROVENANCE-CLEAR + RIGHTS-CLEAR + SECRET-SCRUBBED + MOAT-SAFE`

Software also needs an explicit software license and clean-consumer packaging before it should be represented as an openly reusable software package.
